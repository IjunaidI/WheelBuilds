# WB-095 · SEO & shareability — design

> G11 Wave 4 (final). Findings **X1, X2, X3** ([audit §X](../../future/plans/2026-07-13-ux-completeness-audit.md)).
> Re-verified against current `main` (`d92089e`) 2026-07-15 — evidence inline. Storefront only.
> **Lands after WB-086** (which deletes the two `"| Medusa Store"` titles + the 404 canonical + the sitemap taxonomy block) and **before WB-096** (both patch `middleware.ts`).

## Problem
Every share of this store renders the **boilerplate "Next.js Starter Template / MEDUSA STORE" screenshot** — [`app/opengraph-image.jpg`](../../../storefront/src/app/opengraph-image.jpg) and [`twitter-image.jpg`](../../../storefront/src/app/twitter-image.jpg), both untouched since the initial commit, both auto-adopted site-wide by Next's file convention. `public/favicon.ico` is the same story. PDP `generateMetadata` sets no `openGraph.images`, so even a product link shares the starter screenshot instead of the wheel. The root layout ([layout.tsx:29-31](../../../storefront/src/app/layout.tsx#L29-L31)) sets nothing but `metadataBase` — no title template, so every page hand-rolls its own suffix inconsistently.

No page emits a canonical. **The duplicate-content mechanism is worse than the audit assumed**: `/de` is not an unknown prefix — `seed.ts:139-151` seeds a real EUR region covering `gb,de,dk,se,fr,es,it`, so `regionMap.has("de")` is **true**, `middleware.ts:153-163` returns `next()`, and `/de/products/<handle>` serves a live, indexable, **EUR-priced** duplicate of every US page. A fix gated on `regionMap.has(code)` would never fire — the redirect must be an explicit `code !== DEFAULT_REGION` check, independent of what regions exist.

And env fallbacks silently poison prod: `getBaseURL()` ([env.ts:1-3](../../../storefront/src/lib/util/env.ts#L1-L3)) falls back to `https://localhost:8000`, feeding `metadataBase`, canonical resolution, `robots.txt`'s `sitemap:` line and every `<url>` in the sitemap; a missing `NEXT_PUBLIC_SEARCH_ENDPOINT` ([meilisearch.ts:9-11](../../../storefront/src/lib/meilisearch.ts#L9-L11)) points at loopback and Discovery's swallow-and-return-empty adapter ships a **silently empty catalog** with no error anywhere. [`check-env-variables.js:3-10`](../../../storefront/check-env-variables.js#L3-L10) validates exactly one var: the publishable key.

## Decisions (defaults)
- **OG art = code, not an asset.** No art tooling here and no brand mark exists in `public/`. Generate the share image with `next/og` `ImageResponse` — dark ground, "WHEEL/BUILDS" in Antonio (already loaded), orange rule. Zero binary assets, tracks the design tokens, reviewable as a diff. Same for the favicon via `app/icon.tsx`. If a designer later supplies real art, dropping a static file in the same segment replaces it with no other change.
- **Fail the build, don't ship localhost.** `check-env-variables.js` requires all four load-bearing vars. A build failure with a clear message beats silently publishing `https://localhost:8000` canonicals to Google or shipping an empty catalog. `.env.local.template` already ships all four, so local dev is unaffected — **but this is a deliberate deploy gate**: confirm all four exist in Railway before merging (see Deploy).
- **Belt *and* braces on `getBaseURL()`.** Even with the check in place, `sitemap.ts`/`robots.ts` detect the localhost fallback, log loudly, and emit statics-only rather than publish loopback URLs.
- **Canonical target = `DEFAULT_REGION` (`us`)**, consistent with WB-071 F-D's single-region lock. Not hreflang — there is no localized catalog to point at; a second region would be a real project, and this decision reverses cleanly if that happens.
- **`lastModified` only if real.** Emit it from the indexed `created_at` when the doc carries one; otherwise **omit the field** rather than stamp `new Date()`, which would tell crawlers every URL changed on every deploy.

## Design (storefront only)
1. **Share images + favicon (X1).** Delete `app/opengraph-image.jpg`, `app/twitter-image.jpg`, `public/favicon.ico`. Add `app/opengraph-image.tsx` + `app/twitter-image.tsx` (`ImageResponse`, 1200×630) and `app/icon.tsx`. **The middleware matcher must exclude the three generated routes** (`/opengraph-image`, `/twitter-image`, `/icon`) — the current matcher ([middleware.ts:199-201](../../../storefront/src/middleware.ts#L199-L201)) excludes `favicon.ico` and `.png`/`.jpg` literals but nothing that would match these, so without this they'd 307 to `/us/icon` → 404. This is the same class of trap as WB-096's `_next/image` note; that line is edited by both specs — WB-095 lands first.
2. **Title template (X1).** Root layout: `title: { template: "%s | Wheel Builds", default: "Wheel Builds — Wheels & Tires With Live Fitment" }`. Strip the now-redundant hand-rolled `| Wheel Builds` suffix from the PDP ([products/[handle]/page.tsx:37](../../../storefront/src/app/[countryCode]/(main)/products/[handle]/page.tsx#L37)). Grep for surviving `Medusa Store` **titles** after WB-086 lands (its two pages carry the only ones; body copy in account/register/side-menu is out of scope).
3. **PDP OG (X1).** `openGraph: { images: [product.thumbnail], title, description }` + matching `twitter` in the PDP `generateMetadata` — the vendor CDN image, so no art problem.
4. **Canonicals (X2).** `alternates.canonical` on every indexable page — home, `/store`, `/tires`, PDP — always on the `DEFAULT_REGION` prefix, built from `getBaseURL()`. Absolute, not the bare-relative form that produced WB-086's 404.
5. **Region 301 (X2).** In `middleware.ts`, **after** the fail-open block (lines 131-149 — do not fold it into that branch), 301 any 2-letter prefix that isn't `DEFAULT_REGION` to the same path+query under `DEFAULT_REGION`. Gate on `code !== DEFAULT_REGION`, **never** on `regionMap.has(code)` (see Problem). Country-code-less URLs keep their existing 307. Note the deliberate scope call: during a backend outage the fail-open branch still passes `/de/...` through untouched — WB-081's behavior is preserved on purpose rather than made "more correct" under an outage.
6. **JSON-LD (PDP only).** `Product` (name, brand, image, `offers`: live `priceCents`/100, `USD`, availability from the existing stock state) + `BreadcrumbList`. Both PDP breadcrumb components ([wheel](../../../storefront/src/modules/product-detail/components/breadcrumb/index.tsx), [tire](../../../storefront/src/modules/product-detail/components/tire/breadcrumb.tsx)) omit a Home root, so the JSON-LD synthesizes that first crumb rather than reusing their segment array verbatim.
7. **Sitemap `lastModified`.** From the indexed `created_at` if present in the returned doc; otherwise omit (see Decisions). Do not add a backend Meili settings change to this chunk — if `created_at` isn't in `displayedAttributes`, omit the field and note it; a settings change needs a backend restart and belongs with a re-sync chunk, not here.
8. **Env guards (X3).** `check-env-variables.js` requires `NEXT_PUBLIC_BASE_URL`, `NEXT_PUBLIC_MEDUSA_BACKEND_URL`, `NEXT_PUBLIC_SEARCH_ENDPOINT`, `NEXT_PUBLIC_SEARCH_API_KEY` (plus the existing publishable key). `sitemap.ts` + `robots.ts` log loudly and emit statics-only when `getBaseURL()` is the fallback.

## Verify
`npx next build` (gates the `"use server"` rule and the ImageResponse routes) + `npx tsc --noEmit` at/below baseline. Vitest: canonical builder pins the `us` prefix + absolute form; the middleware region rule (`/de/store?q=x` → 301 `/us/store?q=x`; `/us/store` untouched; no-prefix keeps its 307; **`regionMap` containing `de` does not suppress the redirect** — the regression this whole finding turns on). Smoke: `/opengraph-image`, `/twitter-image`, `/icon` all 200 (not 307→404); a PDP's `<head>` carries a product-thumbnail `og:image`, an absolute `/us` canonical, and valid `Product` + `BreadcrumbList` JSON-LD; `/de/store` → 301 `/us/store`; unsetting `NEXT_PUBLIC_BASE_URL` fails `next build` with a named error.

## Deploy
Storefront rebuild. **Pre-merge gate: confirm `NEXT_PUBLIC_BASE_URL`, `NEXT_PUBLIC_MEDUSA_BACKEND_URL`, `NEXT_PUBLIC_SEARCH_ENDPOINT`, `NEXT_PUBLIC_SEARCH_API_KEY` are all set in every Railway storefront environment** — this change turns "silently broken" into "won't build", which is the intended trade but must not be discovered at deploy time. No migration, no backend change.

## Out of scope
Real brand art (the generated mark is a placeholder a designer can replace by dropping a file in the same segment). hreflang / a real EUR catalog / i18n — a separate project (WB-071 F-D). JSON-LD beyond the PDP (Organization/WebSite/SearchAction). Meili `displayedAttributes` changes for `lastModified`. The `"Medusa Store"` body copy in account/register/footer (titles only here).
