**Goal:** Fix the eleven verified bugs from the 2026-07-10 audit — one commit per bug, failing-test-first wherever a pure seam exists — so tire fit-filters clear honestly, logged-in customers' orders reach their account, checkout failures show real copy, a finish switch can't cart a wrong-pattern wheel, and the backend `tsc` gate reaches 0 errors.

The wiring/UX bugs (B2 error channel, B3 cart transfer, B4 finish desync, B5 SFTP status, B7/B9/B10/B11) are verify-driven. B4 and B8 are two ends of the same defect and ship together.

**Tech Stack:** Storefront Next.js 15 / React 19, vitest (`test:unit`). Backend MedusaJS 2.13.6, jest via `@swc/jest` (`test:sync`), `tsc --noEmit` as the B11 gate.

## Global Constraints

- **One commit per bug** (B4+B8 share one commit). Keep them independently revertable.
- **Two test frameworks:** storefront pure helpers → **vitest** (`import { describe, it, expect } from "vitest"`); backend → **jest** via `pnpm test:sync`. B11 is a `tsc` check, not a unit test.
- **`redirect()` throws `NEXT_REDIRECT`** — the B3 cart transfer must run BEFORE `redirect()`; B2 must not surface `NEXT_REDIRECT` into an error banner.
- **`getAuthHeaders()` is async — await it** at every new call site (un-awaited spreads silently drop the Authorization header).
- **Don't fork `shouldStripFit`** — it's already param-set-agnostic (takes booleans). B1 reuses it and only adds a tire-specific key tuple.
- **B5 has a twin** in `runStockOnly` — fix the terminal-status decision once (a pure helper) and apply to both `executeRun` and `runStockOnly` so they can't drift.
- **B6 must mirror the existing `--confirm-host` contract** (host from `new URL(DATABASE_URL).hostname`, echoed in the request body, mismatch = 4xx). Reuse the dev-wipe script's shape.
- **pnpm may not be on PATH (Windows).** Use `npx -y pnpm@9.10.0 <script>` or the local `.bin` binaries; `npx jest`/`npx vitest`/`npx tsc` work.

export function hostFromDatabaseUrl(url?: string): string | null {
  if (!url) return null
  try { return new URL(url).hostname || null } catch { return null }
}
export function confirmMatches(body: { confirm?: string } | undefined, url = process.env.DATABASE_URL): boolean {
  const host = hostFromDatabaseUrl(url)
  return !!host && !!body?.confirm && body.confirm === host
}
